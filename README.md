# 🎮 Office Voxel

Game 3D voxel ringan berbasis web dengan simulasi kehidupan kantor.

## 🚀 Mulai Game

### 👉 [▶️ MULAI WEB](https://axynera.github.io/gameweb/)

Klik tombol di atas untuk membuka game langsung di browser.

> Jika GitHub Pages belum aktif, buka **Settings → Pages** pada repository ini lalu pilih **GitHub Actions** sebagai source.

## 🕹️ Cara Main

Tidak perlu keyboard atau controller.

- Klik **MULAI DEMO** saat game terbuka.
- Karakter akan berjalan otomatis mengelilingi kantor.
- Karakter berpindah tugas: mengambil dokumen, mengirim laporan, bekerja di komputer, rapat, dan istirahat.
- Waktu dan uang dalam game berjalan otomatis.

## ✨ Fitur

- 🌐 Bisa dimainkan langsung di browser
- 🧊 Dunia 3D voxel
- 🏢 Lingkungan kantor
- 🤖 Karakter bergerak otomatis
- 💻 Sistem tugas kantor sederhana
- 🕐 Waktu simulasi berjalan otomatis
- 💰 Uang bertambah selama bekerja
- 📱 Responsif untuk HP dan PC
- ⚡ Ringan, tanpa backend
